# AIr Automation may host UI review evidence

- Date: 2026-10-01
- Status: accepted
- Authoritative sources: [`AGENTS.md`](../../AGENTS.md),
  [`.agents/skills/web-ui-demo/SKILL.md`](../../.agents/skills/web-ui-demo/SKILL.md)

Video demonstrations and screenshots for visible web UI changes may be
attached either directly to the GitHub pull request or to an AIr Automation
run. The pull request description must link to current, reviewed evidence in
either location. Evidence hosted by an AIr Automation run is sufficient for
marking the pull request ready for review once the repository's other
completion and CI requirements are met.

Review this decision if the repository stops using AIr Automation or adopts a
different authoritative evidence store.
